# Kembara Keselamatan Diri — Pendidikan Kesihatan Tahun 3

## Kandungan
- `index.html` — aplikasi kendiri (HTML, CSS dan JavaScript dalam satu fail).
- 25 soalan objektif dengan pilihan jawapan, jawapan betul dan penerangan.
- Nota berperingkat, pautan video YouTube, permainan pengukuhan, audio menggunakan Web Speech API jika disokong, markah, bintang, lencana dan laporan boleh dicetak.
- Kemajuan kuiz disimpan dalam localStorage pelayar pada peranti yang sama.

## Cara menggunakan
1. Muat turun `index.html`.
2. Buka fail itu dengan Chrome, Edge, Firefox atau Safari versi moden.
3. Masukkan nama murid dan tekan **Mula Pembelajaran**.
4. Internet diperlukan untuk membuka video YouTube. Nota, permainan dan kuiz berfungsi secara setempat.
5. Pada halaman keputusan, pilih **Cetak / Simpan PDF** dan pilih “Save as PDF” jika disediakan oleh pelayar.

## Kurikulum
Aplikasi memfokuskan **Pendidikan Kesihatan Tahun 3, PEERS, Unit 11: Jaga Diri Sihat Emosi**, komponen **7.0 Keselamatan**:
- **SK 7.1** Kemahiran kecekapan psikososial untuk menjaga keselamatan diri.
- **SP 7.1.1** Menyatakan maksud ancaman sekeliling.
- **SP 7.1.2** Membincangkan persekitaran yang boleh mengancam keselamatan diri.
- **SP 7.1.3** Mengaplikasikan langkah-langkah mengelakkan situasi yang boleh mengancam keselamatan diri.
- **SP 7.1.4** Menjana idea cara mengelakkan diri daripada situasi yang boleh mengancam keselamatan diri.

Standard di atas dipadankan berdasarkan maklumat penerangan video pembelajaran berkaitan DSKP Tahun 3 dan RPT Pendidikan Kesihatan Tahun 3 yang ditemui dalam sumber awam. Sila semak DSKP dan RPT rasmi yang digunakan oleh sekolah sebelum menjadikan maklumat ini rekod kurikulum rasmi.

## Penerbitan melalui GitHub Pages
1. Log masuk ke GitHub dan cipta repository baharu, contohnya `kembara-keselamatan-tahun3`.
2. Muat naik `index.html` ke akar repository. (Jika menggunakan ZIP, ekstrak dahulu.)
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/(root)`, kemudian tekan **Save**.
6. Tunggu proses penerbitan selesai. GitHub akan memaparkan URL sebenar dalam halaman Pages. Jangan anggap URL wujud sebelum ia dipaparkan oleh GitHub.
7. Buka URL yang dipaparkan untuk menguji aplikasi pada telefon dan komputer.

## Nota teknikal / had
- Aplikasi tidak menghantar nama atau markah ke pelayan. Kemajuan disimpan setempat pada pelayar dan mungkin hilang jika data laman dibersihkan atau peranti/pelayar bertukar.
- Audio pertuturan menggunakan suara Bahasa Melayu yang tersedia pada peranti. Sokongan suara berbeza mengikut pelayar dan sistem operasi.
- Fungsi cetak bergantung pada pelayar.
- Pautan video memerlukan sambungan internet.
- Aplikasi telah disemak secara statik untuk struktur aliran dan bilangan 25 soalan. Ujian pelayar langsung merentas semua peranti tidak dapat dijamin daripada persekitaran penjanaan fail ini; guru disaran membuat ujian ringkas sebelum digunakan dengan murid.
